# VITyarthi-TIC-TAC-TOE-
This is my project for the vityarthi online course for introduction to problem solving and programming
### Tic-Tac-Toe Game

This project is a simple and interactive **Tic-Tac-Toe game developed using Python**. The game is designed for two players, where one player uses **X** and the other uses **O**. Players take turns placing their symbols on a 3×3 grid, and the player who gets three matching symbols in a row, column, or diagonal wins the game.

The project uses basic Python concepts such as **variables, lists, loops, conditional statements, functions, and user input**. It also includes logic to identify the winner and detect a draw when all positions are filled.

The main objective of this project is to create an enjoyable game while applying and demonstrating fundamental Python programming and problem-solving skills.
